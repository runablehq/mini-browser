# mini-browser

A browser CLI for agents, built with [Bun](https://bun.com) and Puppeteer.

## Install

```bash
bun install
```

## Build

Compile into a single binary:

```bash
bun run build
```

This produces `dist/mb`.

## Usage

```bash
./dist/mb --help
```

Or link it globally:

```bash
bun link
mb --help
```
